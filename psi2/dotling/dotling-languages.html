The Dotling Languages

A family of synthetic token streams for testing whether the optimal multi-token-prediction horizon n* tracks the temporal grain of the data — dots are tokens, runs of dots are words, and every language dials one structural knob.

Hypothesis

MTP is a tuning window. The cheapest way for a model to satisfy n parallel future-token losses is to represent the latent unit that spans roughly n tokens. When n matches the natural unit length (a word), the residual stream is forced to encode unit identity + phase — exactly what a linear probe reads out. Push n past the unit boundary and the far heads mostly see irreducible cross-unit entropy: gradient noise. AuriStream: 5 ms cochlear tokens, word decoding peaks at n = 40 ≈ 200 ms ≈ one spoken word; pitch (a fast local feature) prefers n = 1. If the hypothesis is right, each Dotling language below has a predictable n* — readable off its mutual-information decay curve before training anything.
